# Project: heymoko | Android Developer Portfolio

## Overview
A modern, framework-less portfolio website for an Android Developer (heymoko), featuring a strong personal narrative, clear experience highlights, and polished visuals tailored for recruiter and interviewer attention.

## Project Outline
- **Entry Point:** `index.html`
- **Styling:** Embedded CSS in `index.html`
- **Behavior:** Lightweight scroll reveal and dynamic footer year via inline JavaScript
- **Fonts:**
  - `Bebas Neue`: Headings and logo
  - `Poppins`: Body text
  - `Noto Sans KR`: Korean text

## Current Change Plan: Expand projects with a modernization rebuild
### Purpose
Present ColorLoverLab as a work project and add MyColover as a separate modernization rebuild project, so the portfolio shows both production experience and up-to-date Android reimplementation work.
